# Sky Crizosti | Portfólio Profissional & Currículo

**Engenharia de Software · Desenvolvimento de Software · Inteligência Artificial Aplicada · UX/UI · Análise de Dados**

Portfólio profissional desenvolvido para apresentar minha trajetória acadêmica, experiência profissional, projetos, pesquisas científicas e competências na área de tecnologia.

O projeto foi concebido como uma experiência digital própria, integrando desenvolvimento web, design de interfaces, animações e organização de conteúdo profissional em uma aplicação responsiva e interativa.

**Acesse o portfólio:** [Sky Crizosti — Portfólio](https://purple-mud-0af3acd10.1.azurestaticapps.net/)

---

## ✦ Sobre o projeto

O portfólio foi desenvolvido com o objetivo de transformar um currículo tradicional em uma experiência digital mais completa, interativa e acessível.

A aplicação centraliza informações profissionais e acadêmicas, permitindo apresentar não apenas experiências e qualificações, mas também projetos desenvolvidos, pesquisas, habilidades técnicas e serviços oferecidos.

O conteúdo contempla:

- Trajetória acadêmica em Engenharia de Software.
- Formação complementar e especialização em Engenharia de Software com foco em IA Aplicada.
- Experiência profissional e atuação em gestão de processos.
- Projetos acadêmicos, pessoais e profissionais.
- Protótipos e trabalhos de UX/UI desenvolvidos no Figma.
- Publicações e pesquisas científicas.
- Competências técnicas e interpessoais.
- Conhecimentos em desenvolvimento, inteligência artificial, dados e tecnologias digitais.
- Idiomas.
- Catálogo de serviços de desenvolvimento web.
- Canais de contato profissional.

A proposta é reunir apresentação profissional, demonstração prática de competências e prestação de serviços em um único ambiente digital.

A identidade visual combina **estética editorial, tecnologia e personalidade**, utilizando predominantemente tons de roxo, lilás, rosa, branco e dourado.

---

## ◌ Objetivos do projeto

O desenvolvimento do portfólio atende a diferentes objetivos profissionais:

1. **Apresentação profissional:** disponibilizar informações sobre formação, experiências e competências.
2. **Demonstração técnica:** apresentar projetos e aplicações desenvolvidos ao longo da trajetória acadêmica e profissional.
3. **Documentação de projetos:** centralizar referências, tecnologias e descrições dos trabalhos realizados.
4. **Presença digital:** estabelecer um canal profissional de apresentação e contato.
5. **Prestação de serviços:** apresentar soluções de desenvolvimento web para profissionais e empresas.
6. **Evolução contínua:** manter um registro atualizado do desenvolvimento de competências e da trajetória profissional.

## ✦ Destaques da aplicação

### Desenvolvimento

Aplicação desenvolvida com **React e Vite**, utilizando componentes reutilizáveis e organização modular para facilitar manutenção, expansão e evolução do código.

### Motion Design

As animações e transições são implementadas com **Framer Motion**, proporcionando movimentos sutis durante a navegação e a apresentação das seções.

### Interface e experiência do usuário

A interface foi planejada considerando:

- Clareza e organização das informações.
- Hierarquia visual.
- Responsividade.
- Consistência da identidade visual.
- Acessibilidade e usabilidade.
- Navegação intuitiva.
- Experiência em diferentes dispositivos.

### Conteúdo profissional

As informações apresentadas são estruturadas para refletir a trajetória acadêmica e profissional, mantendo coerência entre currículo, projetos, pesquisas e competências.

### Arquitetura modular

A aplicação utiliza componentes independentes e arquivos de dados organizados por domínio, facilitando atualizações sem exigir alterações generalizadas na estrutura do projeto.

## 🚀 Instalação e execução local

### Requisitos

Antes de executar o projeto, certifique-se de possuir:

- [Node.js](https://nodejs.org/) instalado.
- npm, incluído na instalação do Node.js.
- [Git](https://git-scm.com/), para clonar e versionar o repositório.
- Editor de código de sua preferência, como o [Visual Studio Code](https://code.visualstudio.com/).

### 1. Clonar o repositório

```bash
git clone https://github.com/SkYantS28/curriculo-sky.git
```

### 2. Acessar o diretório

```bash
cd curriculo-sky
```

### 3. Instalar as dependências

```bash
npm install
```

### 4. Iniciar o ambiente de desenvolvimento

```bash
npm run dev
```

Após a inicialização, o Vite disponibilizará a aplicação em um endereço local exibido no terminal. Normalmente:

```text
http://localhost:5173
```

### 5. Gerar a versão de produção

```bash
npm run build
```

O processo gera os arquivos otimizados da aplicação no diretório:

```text
dist/
```

### 6. Visualizar a versão de produção

Para executar uma prévia local do build:

```bash
npm run preview
```

## ☁️ Infraestrutura e deploy

O projeto está hospedado no **Microsoft Azure Static Web Apps**, com integração ao GitHub para automatização do processo de publicação.

**Endereço publicado:**

[https://purple-mud-0af3acd10.1.azurestaticapps.net/](https://purple-mud-0af3acd10.1.azurestaticapps.net/)

### Fluxo de publicação

A integração utiliza GitHub Actions para executar o processo de build e publicação da aplicação.

O workflow está localizado em:

```text
.github/workflows/azure-static-web-apps.yml
```

O fluxo automatizado é responsável por:

1. Identificar alterações no repositório conforme os gatilhos configurados.
2. Preparar o ambiente de execução.
3. Instalar as dependências necessárias.
4. Executar o processo de build.
5. Gerar os arquivos de produção no diretório `dist/`.
6. Encaminhar os arquivos para publicação no Azure Static Web Apps.

### Segurança das credenciais

O token de publicação do Azure é armazenado como um **GitHub Actions Secret**.

Credenciais, tokens e informações sensíveis de infraestrutura não devem ser incluídos diretamente no código-fonte ou versionados no repositório.

## 🎨 Identidade visual e direção de design

A identidade visual foi desenvolvida para fugir do padrão convencional de portfólios de desenvolvedores, combinando referências editoriais e elementos de interfaces digitais contemporâneas.

### Conceito visual

**Tecnologia com identidade.**

A direção visual combina referências de:

- Design editorial.
- Portfólios contemporâneos.
- Interfaces de produtos digitais.
- Tipografia expressiva.
- Composição assimétrica.
- Motion design.
- Minimalismo com elementos de personalidade.

### Tipografia

| Fonte | Aplicação |
|---|---|
| Playfair Display | Títulos e elementos editoriais |
| DM Sans | Textos, informações e elementos da interface |

### Paleta de cores

A identidade visual utiliza uma combinação de:

- Roxo profundo.
- Roxo escuro.
- Lilás.
- Rosa.
- Dourado.
- Branco.
- Tons escuros de apoio.

A proposta é construir uma experiência tecnológica e profissional sem recorrer à estética convencional de interfaces hacker, neon ou elementos excessivamente futuristas.

### Responsividade

A interface é planejada para se adaptar a diferentes dimensões de tela, mantendo a organização das informações e a experiência de navegação em dispositivos móveis e desktops.
